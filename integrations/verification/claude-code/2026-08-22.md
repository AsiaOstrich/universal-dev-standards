## Verdict

**pass (P7 only)** — on this tool, this task, this day, the `uds init`-generated
CLAUDE.md's standards index was enough to get the relevant `.ai.yaml` opened and its
body applied: all three index-arm runs produced codes in the file's
`<PREFIX>_<CATEGORY>_<NUMBER>` house scheme and cited number-range semantics that exist
only in the file body. The claim "the index is sufficient for rules to take effect"
**survives falsification for Claude Code** — and fails for Codex the same day
(1/3, see `../codex/2026-08-22-P7.md`), so this is a per-tool answer, not a general one.

This run does **not** make Claude Code "verified" in the R1/REGISTRY sense: P7 measures
the distribution channel, not the tool's compliance with the active probe set
(P2/P4/P5 remain unrun for this tool). REGISTRY.json is deliberately left untouched.
