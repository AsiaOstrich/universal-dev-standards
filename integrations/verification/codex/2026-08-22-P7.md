## Verdict

**fail** — but the failure has changed shape since 2026-07-23, and the session logs
pin it down:

- 2026-07-23 (P2): Codex read the index, listed 65 standards, **opened none**.
- 2026-08-22 (P7): all three index-arm runs engaged with `.standards/`. The passing run
  searched for the relevant file and applied `error-codes.ai.yaml` correctly

index gets *something* opened, positionally, not the file the task requires. A rule's
effectiveness through this channel currently depends on where it sits in a 69-line list.

not established) and raw material: `../_baselines/codex-0.145.0/p7-distribution/`.
