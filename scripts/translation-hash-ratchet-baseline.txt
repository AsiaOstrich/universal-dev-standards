# XSPEC-392 R6 棘輪基線 —— 既有的無 source_hash 翻譯
#
# 這張清單**不是「沒問題的檔案」**，是「在到期日前不擋你的欠債」。
# source_hash 是 UDS 自己發明的 anti-lie check（雜湊來源內容，不靠人記得更新），
# 而它只到達 804 份裡的 210 份；下列每一份的內容漂移在結構上偵測不到。
#
# 🔴 **不要為了清空這張清單而批次蓋雜湊。** 蓋雜湊是宣稱「此刻與來源同步」，
# 而那件事沒有人驗證過；錯誤的宣稱會把真的漂移重新藏起來。
# 正確做法：確認某份翻譯真的跟上來源之後，用 refresh-translation-hash.ts 蓋它一份，
# 然後從這張清單刪掉那一行。
#
# ⚠️ **分母與 check-translation-sync.sh 不同，這是刻意的**：本清單走訪 locales/ 下
# 所有宣告了 `source:` 的 .md（806 份 → 636 份無雜湊），而 sync checker 走的是它自己的
# 受管清單（804 份 → 594 份）。棘輪要**寬**才不會讓新語系整個目錄靜默漏掉，
# 所以兩個數字不該被拉成一致——**要一致的是它們各自說清楚自己在數什麼**。
#
# 到期 2026-11-25：到期時重新判斷，三選一並寫理由——補完、縮小範圍、或展延並說明。
